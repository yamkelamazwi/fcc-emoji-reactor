# Emoji Reactor

An interactive emoji reaction app built with HTML, CSS, and JavaScript. Users can react by clicking emoji buttons, and each reaction count updates dynamically.

## Features

- Interactive emoji reaction buttons
- Real-time reaction count updates
- Count limit handling
- Dynamic DOM updates
- Responsive and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

- DOM manipulation and updating content dynamically
- Working with event listeners and user interactions
- Selecting multiple elements using `querySelectorAll()`
- Iterating through NodeLists with `forEach()`
- Creating reusable functions
- Accessing and updating element content with JavaScript
- Using conditional logic to control application behavior
- Writing cleaner and more organized JavaScript code
- Debugging and troubleshooting JavaScript logic
